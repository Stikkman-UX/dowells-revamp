# Usage (run fullstack app on your machine)

## Prerequirements

- [MongoDB](https://docs.mongodb.com/v4.4/installation/) 6.0
- [Node](https://nodejs.org/en/download/) 20.0
- [Redis](https://redis-url)
- [npm](https://nodejs.org/en/download/package-manager/)

Notice: You need client and server runs concurrently in different terminal session, in order to make them talk to each other

## Server-side Usage(PORT: 8000)

### Starting Server and Making Build

```terminal
$ cd server                 // go to server folder
$ npm i                     // npm install pacakges
$ cp .env.example .env      // Update .env file keys
$ npm run dev               // run it locally

// deployment for server app
$ npm run build // this will build the server code to es5 js codes and generate a build folder in src folder
```
